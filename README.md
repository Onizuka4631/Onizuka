# Psia instrukcja obsługi — landing page

Responsywna strona sprzedażowa e-booka PDF „Psia instrukcja obsługi”.

## Uruchomienie
Otwórz `index.html` w przeglądarce albo wdroż repozytorium na Netlify (Build command: puste; Publish directory: `/`).

## Przed publikacją
1. Uzupełnij cenę produktu.
2. Podłącz link checkoutu Naffy / Easycart i zmień demonstracyjny przycisk w sekcji oferty.
3. Uzupełnij dane sprzedawcy, NIP, e-mail oraz prawdziwe linki do regulaminu, polityki prywatności i reklamacji.
4. Skonfiguruj automatyczną dostawę pliku PDF w platformie sprzedażowej. Nie umieszczaj pełnego PDF w publicznym repozytorium.
5. Dodaj wyłącznie autentyczne opinie, jeśli są dostępne.

## Uwagi
- Treść strony opiera się na przekazanym e-booku.
- Nie dodano fikcyjnych opinii ani obietnic rezultatów.
- CTA jest demonstracyjne i nie przyjmuje płatności, dopóki nie zostanie podłączony checkout.
- Układ uwzględnia urządzenia mobilne i `prefers-reduced-motion`.
